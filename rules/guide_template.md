# 디자인 가이드

> 레퍼런스를 올린 뒤 [가이드 자동 작성]을 누르면 AI가 이 문서를 채웁니다. 직접 수정해도 됩니다.
> 시안 피드백에서 "규칙으로 저장"을 체크하면 9번 섹션에 자동으로 누적됩니다.

## 1. 톤앤매너
- 단정한 IR 편집디자인. 귀엽지만 유치하지 않게. AI스럽지 않게.

## 2. 컬러
| 역할 | HEX |
|---|---|
| 배경 | #FFFFFF |
| 메인 텍스트 | #111111 |
| 보조 텍스트 | #747474 |
| 라인/보더 | #E7E7E4 |
| 비교 기준(회색 막대) | #C9C9C6 |
| 포인트 | #FF6B2C |
- 한 장표 강한 포인트 컬러는 1개 + 보조 1개 이하

## 3. 타이포 (16:9 기준)
- 폰트: Pretendard
- 메인 타이틀 28~38pt / 강조 문구 24~32pt / 섹션 제목 16~22pt / 본문 11~15pt / KPI 26~40pt / 캡션·출처 8~10pt

## 4. 그리드 & 여백
- 좌우 여백 6% 이상, 12컬럼 그리드

## 5. 요소 규칙
- 비율(예: N개 중 1개) → 도넛 / 배수 비교 → 비교 막대 / 단계 → 프로세스·화살표

## 6. 배경 규칙
- 흰색 또는 웜아이보리 단색

## 7. 이미지·에셋 생성 규칙
- 실제 로고/캐릭터/스크린샷/굿즈 우선. 생성은 아이콘·배경·추상 오브젝트만.
