# PPT Studio

장표 리디자인 루틴을 자동화하는 로컬 프로그램입니다.

**원본 덱 → AI 기획 → ㅇㅋ → AI가 PPTX를 직접 제작 → 미리보기 확인 → (빨간 펜 / 피드백 / 채팅) → ㅇㅋ → 전체 덱**

사람이 하는 일은 **ㅇㅋ, 피드백, 최종 검수**뿐입니다.

## v2에서 바뀐 점: PPTX 먼저 만들기
시안 이미지를 생성하지 않습니다. AI가 PowerPoint 캔버스에 직접 배치하고, **그 PPTX를 PowerPoint로 렌더링한 이미지**를 보여줍니다.
- **보이는 것 = 받는 파일.** "컨펌한 시안이랑 PPTX가 달라요" 문제가 없습니다.
- 이미지 생성은 아이콘·배경 같은 에셋에만 씁니다. 그래서 AI가 그린 슬라이드 특유의 느낌, 한글 깨짐이 없습니다.
- 에셋 zip에는 **실제로 장표에 들어간 에셋**만 담깁니다.

## 실행
1. Python 3.10 이상 설치 (Windows는 설치할 때 "Add to PATH" 체크)
2. Windows: `run_windows.bat` / Mac: `run_mac.command` 더블클릭
3. 브라우저가 열리면 **설정 → AI 연결 방식** 선택
   - **복붙**: 쓰던 ChatGPT 구독으로 작업 (API 키 불필요)
   - **API 자동**: OpenAI API 키 입력 (사용한 만큼 과금)
   - 흐름만 보려면 **데모 모드**

## 복붙 모드
AI가 필요한 단계마다 화면 위쪽에 **복붙 카드**가 뜹니다.
1. **[① 프롬프트 복사]** → ChatGPT **새 대화**에 붙여넣기 (디자인 가이드, 규칙, 덱 요약이 전부 들어 있어서 매번 새 대화여도 됩니다)
2. 첨부 이미지를 끌어다 놓거나 **[복사]** 후 Ctrl+V (번호 순서대로)
3. ChatGPT 답변을 복사해서 붙여넣고 **[답변 넣고 계속 진행]**
   - 에셋(아이콘/배경) 카드: ChatGPT가 만든 이미지를 올리거나 칸에 Ctrl+V. 필요 없으면 **[건너뛰기]** (PPTX에는 자리표시 박스로 들어감)

그다음 PPTX 생성, 미리보기, 버전, 규칙 저장, 사실 검증은 전부 자동입니다.
- 3장을 동시에 기획하면 카드 3장이 한꺼번에 뜹니다.
- JSON이 잘리거나 형식이 깨지면 다시 붙여넣으라는 안내와 함께 같은 카드가 다시 뜹니다.
- 왕복 횟수를 줄이려고 복붙 모드에서는 AI 자체 검수를 생략하고, 피드백 규칙 추출은 수정 요청과 한 번에 처리합니다.
- 카드를 **[취소]**하면 해당 장표는 오류 상태가 되고, **[다시 시도]**로 이어서 진행합니다.

권장 환경:
- **Windows + PowerPoint**: 정확한 미리보기. 없으면 LibreOffice를 쓰고, 둘 다 없으면 브라우저 근사 미리보기로 표시합니다.
- **[Pretendard 폰트](https://github.com/orioncactus/pretendard/releases) 설치**
- 원본은 **PPTX로 올리기**: 원본 테마·마스터·비율을 유지합니다. 전체 덱은 원본 파일에서 완료된 장표만 교체해서 만듭니다.

## 장표 한 장의 흐름
| 단계 | 누가 | 내용 |
|---|---|---|
| 1. 기획 | AI | 15년차 IR 디자이너 프롬프트 (표지는 표지 전용). 3장씩 동시에 |
| 2. 기획 컨펌 | 나 | ㅇㅋ / 수정 요청 / 기획안 직접 수정 |
| 3. 장표 제작 | AI | 레이아웃 설계 → 필요한 에셋 생성 → PPTX → 미리보기 → **AI 자체 검수 후 1회 자동 수정** |
| 4. 확인·수정 | 나 | 아래 수정 방법 참고 |
| 5. 완료 | 나 | 원하는 버전 확정 → 장표 PPTX / 에셋 zip / 전체 덱 |

## 수정하는 방법 4가지
1. **빨간 펜**: 미리보기 위에 직접 표시하면 AI가 그 영역의 요소를 정확히 찾아 고칩니다.
2. **피드백 + 규칙 저장**: "손글씨 빼"처럼 앞으로도 적용할 말은 규칙으로 저장돼 이후 모든 장표에 자동 적용됩니다 (이 프로젝트 / 모든 프로젝트 선택). 가이드 탭에서 삭제할 수 있습니다.
3. **채팅**: "왜 AI스러워 보일까?" 같은 질문을 할 수 있습니다. 답변 아래 **[이대로 수정 요청]**을 누르면 그 내용으로 수정합니다.
4. **PowerPoint에서 직접 수정 → 업로드**: 고친 파일이 새 버전이 되고, 이후 AI 수정은 그 파일 기준으로 진행돼서 손본 내용이 보존됩니다.

모든 결과는 버전(v1, v2 …)으로 남습니다. 이전 버전을 보고 그 버전을 기준으로 다시 수정하거나 확정할 수 있습니다.

## 커스터마이즈
- `prompts/*.md`: 단계별로 AI에게 보내는 멘트 (평소 말투로 고쳐도 됩니다)
- `rules/global_rules.md`: 모든 프로젝트 공통 금지 규칙 (AI스러움 금지)
- `rules/guide_template.md`: 새 프로젝트 기본 디자인 가이드

데이터는 전부 `projects/` 폴더(이 PC)에 저장됩니다. 화면 상단에 프로젝트별 API 사용량이 표시됩니다.

## exe 빌드
GitHub에 올리면 `.github/workflows/build-exe.yml`이 Windows exe를 만들어 Releases에 올립니다. 빌드 전에 `tools/smoke_render.py`(PPTX 생성·역변환·덱 병합), `tools/smoke_e2e.py`(전체 흐름), `tools/smoke_manual.py`(복붙 모드)로 먼저 검증합니다.
