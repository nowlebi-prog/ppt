2. 실제 게임 화면 / 제품 UI / 실존 인물 사진 / 신규 캐릭터는 생성하지 않는다. 필요한 경우 실제 자산을 쓰거나 목업 자리로 표시하거나 "작업 불필요"라고 명시한다.
